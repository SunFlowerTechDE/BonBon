# @bonbon/mock-terminal

ZVT-Terminalsimulator, TCP auf Port 20007. Beantwortet Registrierung und
Autorisierung, sendet Zwischenstatus.

Muss ueber Konfiguration Erfolg, Ablehnung, Timeout und Abbruch mitten in der
Zahlung liefern koennen — ein Mock, der immer funktioniert, testet nur den
Schoenwetterfall (CLAUDE.md, Ports und Adapter).

Referenz fuer den Nachrichtenaufbau: [Portalum.Zvt](https://github.com/Portalum/Portalum.Zvt).
Die Spezifikation gibt es kostenlos beim [VdTH](https://www.terminalhersteller.de/Downloads.aspx).
