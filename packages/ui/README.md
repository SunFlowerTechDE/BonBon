# @bonbon/ui

React-Komponenten der Kassenoberflaeche: Artikelraster, Bon, Verzehrart-Umschalter,
Zahlungsdialog.

Hier liegt keine Steuer- oder Rundungslogik. Die kommt aus `@bonbon/core`.
Die Umrechnung von Cent nach Euro passiert ausschliesslich hier in der
Darstellungsschicht (CLAUDE.md, Regel 3).

**Status:** Platzhalter, noch ohne React-Abhaengigkeit. Inhalt entsteht in M2.
